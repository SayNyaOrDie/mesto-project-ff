# Проектная работа Mesto

Интерактивная страница: профиль пользователя, карточки мест, лайки и попапы.

## Технологии

- HTML, CSS, БЭМ
- JavaScript
- Webpack
- API Яндекс Практикума

## Сборка и запуск

```bash
npm install
npm run dev
npm run build
npm run deploy
```
